## What this is

An open-source collection of **60+ zero-dependency skills** for AI coding agents and assistants
(Claude Code, Codex, Cursor, WorkBuddy), organized around the
**LGD (Lifecycle Governance Doctrine)** three laws — *registered · evidenced · gated* —
plus a set of general-purpose practitioner skills (prompt governance, memory governance,
skill engineering, finance/blockchain compliance checks).

## Install

Skills are plain `SKILL.md` packages — clone or copy the folder you need:

```bash
git clone https://github.com/zhaoxinghua09-cell/agent-skills.git
# then point your agent at any skill folder, e.g. agent-skills/skills/<name>/SKILL.md
```

See the CN README for the full per-platform install matrix.

## Skill families

| Family | What it covers |
|---|---|
| **LGD moat series** | Session continuity protocol, brain-learning memory, local DPAPI credential vault, agent evolution, evidence-gated operations, skill release gates |
| **Compliance checks** | Finance & blockchain compliance automation, medical-device regulatory helpers |
| **General practitioners** | Prompt governance, memory governance, skill engineering, release QA |

Each skill folder is self-contained: `SKILL.md` + optional scripts, stdlib-only.

## Theory

The underlying theory — **凡自治之物 · 有籍 · 有证 · 有门禁** (every self-governing entity shall be registered, evidenced, gated) — is documented in the companion repository
[`lgd-theory`](https://github.com/zhaoxinghua09-cell/lgd-theory) (English formal term: **Evidence-Gated AI Lifecycle Governance**).
