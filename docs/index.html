One ruler, four candidates 同一把尺子

以下分数由同一份代码算出：同一套权重、同一批阻断规则。竞品通过公开渠道安装后本地实跑。

横向为总分（满分 100）。两侧竞品均为公开安装后实测，未做任何调参。

这把尺子量的是「可验证交付」，不是「策略厚度」。它给分给的是：有没有测试、文档参数与脚本对不对得上、有没有能跑的 demo、有没有互链与许可声明。它不给分给的是：语义规则多细、参考资料多深、行业洞察准不准。换成「策略覆盖度」这把尺子，排序可能翻转。

注意最后一列：竞品的说明性占比仍低于我们（27–30% vs 35–39%）。我们总分领先，靠的是渐进披露、决策表、可复现交付这几维，不是靠知识密度。这一维我们仍然输，且短期内难赢。

120 分制不是官方分。它是我按 skill-judge 的维度定义自己实现的启发式版本（正则 + 逐行统计，不含 LLM 判定）。竞品的 88 / 91 也是我用同一套代码算的，不是它们的官方成绩。同一个方既做尺子又做被测，存在利益冲突——所以我把算法、数据、复跑命令全部公开，允许任何人推翻我。

Run it yourself 自己跑一遍

三条命令，不装依赖、不发网络请求。装完就能给自己的技能打分，拿到整改清单，改完再跑一遍。

# install the reviewer
clawhub install @zhaoxinghua09-cell/lgd-skill-review

# score a skill directory (add --run to actually execute its tests)
python scripts/review.py <your-skill-dir> --run

# extra reports: narration ratio, four independent perspectives
python scripts/review.py <your-skill-dir> --token --multi-role

其余三个技能同样一条命令安装：

clawhub install @zhaoxinghua09-cell/summarize-pro
clawhub install @zhaoxinghua09-cell/debug-pro
clawhub install @zhaoxinghua09-cell/wechat-viral-topic

Limits, stated plainly 边界，写在明处

不评业务逻辑正确性。只查结构与声明一致性，不查结论对不对。

不做安全渗透。只做敏感信息与危险调用的静态排查。

不替代人工评审。输出的是证据化清单，不是终审结论。

说明性内容仍占 55–64%。四包中英双语各写一遍，压缩空间受限，这一项只是从「很差」改善到「中等」。

评分口径是自研的。不是第三方标准，只保证同一把尺子前后一致。

可发现性刚起步。页面本身就是在补这一课。
