# 调研出处与证据（Pro 版 · 含工程启示）

> 本文件为 `ai-brain-learning-memory-pro` 的设计依据。每项标注「研究结论」与「工程必须做的」，对应 SKILL.md 第 6 节映射表。

## 一、记忆架构

| 来源 | 研究结论 | 工程启示 |
|------|---------|---------|
| CoALA（TMLR 2024, SUMMARY OF RECENT WORK） | 把 LLM Agent 记忆分工作/长期；长期记忆再分情节/语义/程序性；程序性记忆用**代码**表达 | 记忆系统必须三层独立存储；可复用流程落 skills/ 而非文字 |
| MemGPT（2023） | 用「操作系统」式分层（主上下文/外部存储/归档）模拟人脑，主动在层间搬运 | 实现「压缩+检索」机制，别把全部塞进上下文 |
| Mem0 / Zep | 图记忆 + 有效性区间，区分「现在真」与「上个月真」 | 记忆条目带时间戳/有效性，冲突以最新为准 |
| Anthropic memory tool（2025） | 长任务三心法：Compaction / 随手笔记 / 子代理浓缩；搭配后 token 省 84%、表现 +39% | 长任务必须主动管理记忆，不是只靠上下文窗口 |

## 二、记忆安全（投毒）

| 来源 | 研究结论 | 工程启示 |
|------|---------|---------|
| OWASP Top 10 for LLM Agents ASI06 | 记忆与上下文投毒成为独立安全条目 | 记忆写入/提取必须纳入安全威胁模型 |
| MINJA（NeurIPS 2025） | 普通用户仅凭构造查询即可投毒，注入成功率 95%+、攻击成功率 70%+ | 绝不能假设「用户输入无害」；写入需校验 |
| MemoryGraft | 伪造「成功经验」植入记忆，Agent 检索后模仿恶意模式（语义模仿启发式） | 记忆默认不可信，关键动作先核实 |
| AgentPoison（NeurIPS 2024） | 知识库/记忆库植入触发词，平均攻击成功率 80%+ | 记忆库本身要审计，不只审即时输入 |
| A-MemGuard（2025） | 高级 LLM 检测器也会漏掉约 66% 投毒条目 | 不能只靠检测器，必须溯源+隔离+人工复核 |

## 三、认知科学证据

| 来源 | 研究结论 | 工程启示 |
|------|---------|---------|
| Ebbinghaus（1885，2015 复现） | 无意义材料 20min 忘 42%、1h 56%、1d 74%、1w 77%；先快后慢 | 写入后必须有复习节点，否则默认遗忘 |
| Cepeda et al.（2006，元分析 317 实验/14000 人） | 分散练习稳定优于集中；间隔随「需保留时长」缩放 | 重访间隔递增，越熟查越稀 |
| Karpicke & Blunt（2011, Science） | 检索练习（主动回忆）比重读多记约 50% | 日志撰写前先回想再补证 |
| Dunlosky et al.（2013） | 十大学习技术中仅主动回忆与间隔重复为「高实用性」 | 别依赖重读/划重点式记忆 |
| Bjork（合意困难） | 检索有一点吃力时长期记忆增强 | 提取留适度难度，不无脑全预读 |
| Tulving / CoALA | 情节经验是语义记忆获取的必要条件（失忆症无法形成新语义） | 必须有当日日志作为语义蒸馏原料 |

## 四、评测电池

- `scripts/memory_eval_battery.py`：配置层 6 维自评（T/R/A/C/E/S，0–5），纯本地、零真实凭据、可重跑、可附发布说明。
- 口径说明：配置层自评衡量「系统在本地闭环下的设计合规度」，非真实对抗强度；真实红队另计。
