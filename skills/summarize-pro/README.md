# summarize-pro · 增强内容总结（v1.3.0）

把长内容变成能直接用的形态：**先选对输出格式，再保证内容忠实**。

## 什么时候用

- 「帮我出个会议纪要」「把这份报告总结一下」「这两篇文档有什么区别」「按时间线梳理一下」「给我 3 条要点」。
- 搜索关键词：总结 / 摘要 / 会议纪要 / 对比表 / 时间线 / 要点提炼 / 笔记整理 / summarize。

## 能力

- 5 大输出格式族：纪要族（结论先行→议题逐条→待办）、对比族（维度×对象表格）、时间线族（日期/事件列表）、要点族（3-7 条可执行要点）、卡片族（标题+结论+关键字段）。
- 忠实性纪律（不可妥协）：只复述原文出现过的信息；原文没说的标「原文未提及」；数字/人名/日期逐字保留；区分事实与观点；不因篇幅压力丢条件。
- 覆盖 8 种语言输入输出（中/英/日/韩/西/法/德/阿），默认跟随用户提问语言。

## 输出骨架

```
一句话总览（不超过 40 字）
——
[按所选格式族展开]
——
待确认/原文未提及的点（如有）
```
