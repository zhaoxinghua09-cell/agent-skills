# 输入 → 输出 示例（摘要）

5 个格式族各一例，**每例都给完整原文，输出每句可在原文逐字定位**。完整示例见：

- `references/examples.md`

| 格式族 | 示例场景 | 核心看点 |
|---|---|---|
| 纪要族 | 站会转写 | 待办含责任人/期限，原文未提及处显式标注 |
| 对比族 | 自建 vs SaaS | 维度×对象表格，不加原文没有的优劣结论 |
| 时间线族 | 项目回顾 | 一行一事，日期与原文一致 |
| 要点族 | 会议邮件 | 3–7 条，每条可直接执行 |
| 卡片族 | 文献摘要 | 标题 + 一句话结论 + 3 个关键字段，只搬运原文数值 |
