# 项目治理骨架（可直接复制）

把下面这套结构复制到任何项目根目录，即获得「籍 · 证 · 门」三件套。

## 目录结构

```
你的项目/
├── .governance/
│   ├── registry.jsonl      L1 任务籍（只增不改）
│   ├── evidence.jsonl      L2 指纹快照与变更（只增不改）
│   ├── gates.jsonl         L3 高危动作与确认记录
│   └── EVIDENCE_REPORT.md  对外举证报告（每次 verify 生成）
├── scripts/
│   └── audit_chain.py      证据链引擎（零依赖）
└── ... 你的项目文件
```

## 三条命令搞定日常

```bash
# 开工：立籍
python scripts/audit_chain.py init --root . \
  --task "把 20 份技术文档统一排版" \
  --actor "AI(Claude) + 人工复核(张三)" \
  --basis "docs/spec.md"

# 中途：随时留证（每次批量改动后跑一次）
python scripts/audit_chain.py seal --root . --note "统一了标题层级与表格样式"

# 高危动作前：登记闸门
python scripts/audit_chain.py gate --root . \
  --action "对外发送" --detail "把成品发给客户A"

# 收工：复算并出举证报告
python scripts/audit_chain.py verify --root . --report .governance/EVIDENCE_REPORT.md
```

## 台账字段说明（给需要读台账的人）

### registry.jsonl

| 字段 | 含义 |
|---|---|
| `task_id` | 任务唯一号（`T-年月日时分秒`） |
| `actor` | 谁在干（人 + 模型 + 工具链） |
| `task` | 一句话目标 |
| `basis` | 依据材料清单（路径 + 指纹 + 是否存在） |
| `approved_by` | 谁批的 |
| `ts_utc` / `ts_local` | 双时间戳 |

### evidence.jsonl

| 字段 | 含义 |
|---|---|
| `files` | 全量文件指纹（`路径 → sha256 + size`） |
| `delta` | 与上一快照相比的 `added / modified / removed` |
| `note` | 本轮做了什么 |

### gates.jsonl

| 字段 | 含义 |
|---|---|
| `action` | 高危动作名 |
| `detail` | 详情（收件人/影响范围/内容摘要） |
| `status` | `pending` / `confirmed` / `rejected` |
| `confirmed_by` | 确认人（人工回写） |

## 团队协作时的两条约定

1. **台账进版本库**：`.governance/` 应提交到 git（它本身不含敏感信息），这样多人的记录合并成一条完整链。
2. **`.governance/` 排除在被扫描范围之外**：脚本已内置跳过，否则每次 seal 都会把自己算进去，永远无法收敛。

## 与 git 的分工（常见疑问）

| | git | 本技能台账 |
|---|---|---|
| 管什么 | 代码/文本版本的协作与回滚 | **谁发起、为什么改、谁批的、高危动作谁放行的** |
| 粒度 | commit | 任务 |
| 能否替代 | 不能：git 不知道"谁批的"和"这个动作是否被允许" | 不能：git 更适合内容版本管理，两者互补 |

**结论：不是替代 git，是补上 git 不管的那部分（治理与审批）。**

## 一个最小可用示例（复制即跑）

```bash
mkdir demo && cd demo
cp -r ../ai-governance-audit-chain/scripts .
echo "内容" > a.txt
python scripts/audit_chain.py init --root . --task "试跑" --actor "我"
echo "改了" > a.txt
python scripts/audit_chain.py verify --root .        # 应报 L2 FAIL
python scripts/audit_chain.py seal --root . --note "改 a.txt"
python scripts/audit_chain.py verify --root .        # 应报 可举证，exit=0
```

四行命令、两个状态，这就是全部机制的可见证据。
