# 法律证据链校验（Legal Evidence-Chain Check）

LGD 三律在「法律 / 电子证据链完整性」域的纵深合规工具：证据链时间单调 / 主体一致 / 哈希链不断裂校验（零依赖）。

## 痛点
电子证据链（时间/主体/哈希）断裂难以自动发现，影响证据可采性。

## 快速开始
```bash
python evidence_chain_check.py --help
```

## 三律落地
- 有籍 → 系统/数据身份登记（本域术语）
- 有证 → 证据工件可核验（本域证据类型）
- 有门禁 → 高风险动作过门禁（本域阈值）

## 护城河定位
