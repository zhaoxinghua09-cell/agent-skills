# 调研出处与证据（references）

> 本文件收录 ai-brain-learning-memory v2.1.0 设计与补充所依据的公开研究/标准出处，供追溯与发布自检（发布规矩：references 清单 ↔ SKILL.md 导航表一一核对）。

## 一、AI Agent 记忆系统（2023-2025 前沿）

| 出处 | 说明 | 在技能中的对应 |
|------|------|--------------|
| CoALA: Cognitive Architectures for Language Agents（Sumers, Yao, Narasimhan, Griffiths, TMLR 2024, arXiv:2309.02427, 普林斯顿） | 语言智能体认知架构：工作记忆+长期记忆三分（情节/语义/程序性）+结构化动作空间+决策循环；承 Tulving 记忆三分法与 SOAR/ACT-R 传统 | 第一节「长期记忆二分」、程序性记忆=代码 |
| MemGPT（Packer et al., 2023, UC Berkeley）→ Letta | 类操作系统分层记忆：main context=RAM、archival=disk，模型自编辑记忆 | 分层思想来源 |
| Mem0（ECAI 2025） | pipeline 式事实提取；LOCOMO 基准：相对 OpenAI 内置记忆 +26%、p95 延迟 -91%、token -93% | 「记忆≠RAG」、提取强化 |
| Zep / Graphiti | 时序知识图谱：边带有效性区间（validity interval），可区分"现在真/上个月真" | 双时态一致性工程实现 |
| Anthropic Memory Tool + Context Editing（2025-09 发布，memory_20250818） | 文件系统式记忆工具（view/create/str_replace/insert）+ context editing 自动清理过期工具调用；长任务 token -84%、表现 +39%；三招心法 compaction / structured note-taking / sub-agents | 第二节「长任务记忆三招」 |

## 二、记忆安全（OWASP 与 2024-2025 攻击研究）

| 出处 | 说明 | 技能对应 |
|------|------|---------|
| OWASP Top 10 for LLM & Agentic Applications（2025 版，ASI06 Memory & Context Poisoning） | 记忆投毒列为代理安全独立条目 | 第六节「记忆安全」 |
| MINJA（Dong et al., 2025, NeurIPS 2025, arXiv:2503.03704） | 仅凭普通查询即可投毒记忆，注入成功率 95%+、攻击成功率 70%+，无特权无直写 | 第六节防御依据 |
| MemoryGraft（Srivastava & He, 2025） | 经验嫁接：植入伪造"成功经验"，代理检索后模仿恶意模式（语义模仿启发式） | 第六节「经验嫁接」 |
| AgentPoison（Chen et al., NeurIPS 2024） | 知识库/记忆库触发词投毒，平均攻击成功率 80%+ | 第六节「知识库投毒」 |
| A-MemGuard（2025） | 高级 LLM 检测器仍漏掉约 66% 投毒条目 | 第六节「检测困难」 |

## 三、认知科学证据（人脑学习法）

| 出处 | 说明 | 技能对应 |
|------|------|---------|
| Ebbinghaus（1885）；Murre & Dros（2015 复现） | 遗忘曲线：24 小时不复习丢失 50-70% | 5.1 遗忘曲线 |
| Cepeda et al.（2006, Psychological Bulletin 132(3):354-380） | 间隔效应元分析（317 实验/约 14000 人）：分散练习稳定优于集中；最优间隔随保留时长缩放 | 5.2 间隔重复 |
| Karpicke & Blunt（2011, Science 331:772-775） | 检索练习比重读多记约 50%，且胜过概念图 | 5.5 主动回忆 |
| Dunlosky et al.（2013, Psychol Sci Public Interest 14(1):4-58） | 十大学习技术评级：仅主动回忆+间隔重复为"高实用性"；重读/划重点/总结为低实用性 | 5.5 主动回忆 |
| Roediger & Karpicke（2006, Psychol Sci）；Rowland（2014 元分析 g=0.50） | 测试效应：测试产生比重学更好的长期保持 | 5.5 主动回忆 |
| Bjork（1994, "Desirable difficulties"） | 合意困难：让检索变难反而增强长期记忆 | 5.5 主动回忆 |
| Tulving（1972 记忆三分法；1985 意识层级 Anoetic/Noetic/Autonoetic） | 长期记忆三分：程序性/语义性/情节性；情节记忆对新语义获取不可或缺（失忆症研究） | 第一节「长期记忆二分」 |
| 睡眠记忆巩固（Science 2024 Oliva CA2 重置；Inokuchi 2025 engram-to-be） | 慢波睡眠海马回放→新皮层，记忆巩固 | 5.7 睡眠巩固 |
